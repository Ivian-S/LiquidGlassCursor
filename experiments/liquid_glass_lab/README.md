# Liquid Glass 光学材质实验（V0.2）

这是独立于 V0.1 原生 CUR 构建流程的 WebGL2 视觉算法原型。页面读取 `assets/arrow.svg` 中的 `clipPath#arrowClip`，因此没有重新设计箭头形状，也不会覆盖 V0.1 的 SVG 或输出文件。

## 启动

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe .\experiments\liquid_glass_lab\serve.py
```

然后在 Chrome、Edge 或 Firefox 打开：

```text
http://127.0.0.1:8765/experiments/liquid_glass_lab/
```

页面完全本地运行，不依赖 CDN。请不要直接双击 `index.html`，因为浏览器的 `file://` 安全策略可能阻止读取项目内的 SVG。

## 如何验证真实折射

1. 选择“文字”背景。
2. 把 32px 箭头慢慢移动到细线、`ABCDE 012345` 或代码文字上。
3. 保持“折射”开启，把“折射位移”在 `0` 与默认 `2.8 px` 之间切换。
4. 观察箭头内部的文字边缘：开启时边缘会沿遮罩法线产生局部错位和弯折；关闭或设为 `0` 后，背景位置恢复。
5. 点击“全部关闭”可直接比较原始背景。右下角放大区是实际 32px 区域的 10 倍像素检查。

这不是简单透明覆盖：片元着色器会读取背景纹理，并用 `uv + normal * offset` 重新采样。色散还会对 R、B 通道使用略有差异的采样坐标。

## 默认参数

| 参数 | 默认值 | 目的 |
| --- | ---: | --- |
| 折射位移 | 2.8 px | 让文字边缘产生可见但受控的局部扭曲 |
| 内部模糊 | 0.8 px | 减少高频锯齿，不形成大面积磨砂 |
| 边缘亮度 | 0.32 | 提供轻量 Fresnel-like 聚光 |
| 色散距离 | 0.55 px | 仅在高对比边缘产生很轻的 RGB 分离 |
| 镜面强度 | 0.26 | 左上光源高光，移动时有小幅变化 |

## 实现结构

- `index.html`：控制面板、实际尺寸画布和放大检查区。
- `styles.css`：本地 UI 样式，不包含远程字体或资源。
- `app.js`：SVG 遮罩提取、背景生成、WebGL2/GLSL 光学算法与交互循环。
- `serve.py`：只绑定 `127.0.0.1` 的轻量静态文件服务器。

## 限制

- 浏览器原型只能处理页面内已知背景纹理，不能采集 Windows 桌面。
- 系统 CUR 本身是静态位图，不能执行 Shader；未来需要独立的透明覆盖层或其他 GPU 合成路径。
- 尚未处理多显示器、DPI 缩放、系统鼠标隐藏、点击穿透、输入延迟和前台窗口切换。
- 当前遮罩边缘法线来自栅格遮罩梯度，未来桌面版本可预计算更精确的 SDF/法线纹理。
